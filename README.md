# Cyber Security Task 1 – Security Assessment

## Objective
To understand basic cybersecurity concepts and perform a basic security assessment of a safe test application.

## Task Overview
This project focuses on identifying common security risks and providing recommendations to improve application security.

## Security Areas Covered
- Authentication and Authorization
- Password Security
- Input Validation
- Phishing Awareness
- Common Web Security Risks
- Security Best Practices

## Tools Used
- Browser Developer Tools
- OWASP-based security concepts
- GitHub

## Deliverables
- Security Assessment Report
- Identified Security Risks
- Recommended Security Improvements
- Supporting Screenshots

## Conclusion
This assessment helped in understanding common cybersecurity risks and the importance of implementing basic security practices in applications.# cyberSecurity-Task1
